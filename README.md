
# BDF Lab 3 - REST API

## Project Title
Book Management REST API

## Technologies Used
- Node.js
- Express.js
- SQLite
- JavaScript

## Features
- GET all books
- POST new books
- PUT update books
- DELETE books
- Search books by title
- Sort books by price, title and author
- Pagination using limit and offset
- Filter books by price range
- Input validation
- Proper HTTP status codes

## How to Run

1. Install dependencies:
   npm install

2. Start the server:
   node server.js

3. Open:
   http://localhost:3000/books

## Database
SQLite database with a books table containing:
id, title, author and price.
